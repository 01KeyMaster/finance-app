# Finance App

Личное приложение для учёта доходов и расходов. Версия 1.

## Стек
- Фронтенд: React + Vite + React Router
- Бэкенд: Node + Express (заготовка)
- База: PostgreSQL + Prisma (добавим на следующем шаге)

## Структура
- `client/` — приложение на React (то, что видно на телефоне)
- `server/` — сервер на Express (пока отдаёт тестовые данные)

## Что нужно заранее
- Node.js версии 20 или новее

## Запуск фронтенда
1. Открой папку `client` в терминале
2. `npm install`
3. `npm run dev`
4. Открой адрес, который покажет терминал (обычно http://localhost:5173)

Чтобы открыть на телефоне: телефон и компьютер должны быть в одной Wi-Fi сети, затем набери на телефоне адрес вида `http://192.168.x.x:5173` (его тоже печатает терминал в строке Network).

## Запуск сервера
1. Открой папку `server` во втором окне терминала
2. `npm install`
3. `npm run dev`
4. Проверь в браузере: http://localhost:4000/api/health

## Что работает сейчас
- Три экрана: Главная, Новая операция, Прогноз
- Переходы между экранами
- На экране «Новая операция» переключаются тип и категория
- На экране «Прогноз» развилки пересчитывают сумму
